# AUR package recipe

`PKGBUILD.in` is the reviewed template. The exact `PKGBUILD` is generated by `scripts/render_aur_pkgbuild.py` from the release source distribution so it includes the correct immutable SHA-256 checksum.

The GitHub release workflow attaches that generated file as a release asset. The AUR publishing workflow copies it into the AUR package repository and derives `.SRCINFO` using `makepkg --printsrcinfo` in an Arch Linux container. Do not hand-edit `.SRCINFO`; regenerate it whenever the recipe changes.
