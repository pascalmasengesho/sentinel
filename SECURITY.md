# Security policy

## Supported versions

Security fixes are applied to the latest published minor release of Sentinel.

## Reporting a vulnerability

Do not open a public issue for a potential Sentinel vulnerability. Report it privately to the maintainers through the security-advisory feature of the published GitHub repository, including affected version, impact, reproduction details, and a safe proof of concept.

Do not include credentials, targets, or data from systems you do not own in a report. Maintainers will acknowledge receipt, assess impact, and coordinate a fix and disclosure timeline.
